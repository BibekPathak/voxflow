# VoxFlow

Real-time Voice AI agent runtime: streaming audio, streaming STT/LLM/TTS, VAD,
turn detection, barge-in, cancellation, tool calling, latency observability and
an automated evaluation harness.

> Work in progress. Phase A scaffold (event model, event bus, cancellation
> scopes, structured logging, configuration) is in place. Architecture, setup
> and benchmarks are documented here as the runtime is built out.
